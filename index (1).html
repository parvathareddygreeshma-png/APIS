🔑 Cryptography Laboratory

1. PBKDF2 Key Derivation

Type your own demo password and generate a cryptographic AES-256 key using PBKDF2 + SHA-256.

Type a password and click Generate Key.

2. AES-256-GCM Encryption

Type your own confidential demo message and password. The message is encrypted in the browser.

Type your data and click Encrypt Message.

3. SHA-256 Integrity

Type or edit any record text. SHA-256 creates a fingerprint so changes can be detected.

Edit the text and calculate its SHA-256 fingerprint.

4. Digital Signature

Type your own message. The browser creates an ECDSA P-256 signature and immediately verifies it.

Edit the message and click Sign & Verify.
