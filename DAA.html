How PuzzleSolver Pro Works

1. Problem Representation: Each puzzle is represented as a collection of variables, domains and constraints.

2. Constraint Propagation: The system removes values that cannot satisfy the current constraints before continuing the search.

3. Backtracking: When a selected value produces an invalid state, the algorithm returns to the previous decision and tries another possibility.

4. Heuristic Search: The solver attempts to select the most constrained variable first, reducing unnecessary exploration.

5. Performance Analysis: Nodes explored, constraint checks, backtracks and execution time are measured for every solver.

🧩 Sudoku Solver

Algorithm


The Sudoku solver first finds an empty cell and calculates its legal candidate values. Constraint propagation removes values that conflict with the row, column or 3×3 sub-grid.

The Minimum Remaining Values strategy is used to select a highly constrained cell before recursive backtracking.
