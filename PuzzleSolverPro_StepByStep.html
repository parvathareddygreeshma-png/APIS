How the Framework Works

Step 1 - CSP: Represent the puzzle using variables, domains and constraints.

Step 2 - Constraint Propagation: Remove values that cannot satisfy the current constraints.

Step 3 - Backtracking: Make a choice. If it fails, undo it and return to the previous choice.

Step 4 - Search Space: The invalid choices are removed so the remaining search space becomes smaller.

Step 5 - Visualization: The website shows the complete solving process, one action at a time.
