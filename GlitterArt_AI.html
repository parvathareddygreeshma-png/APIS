🔬 How It Works

1. Image Preprocessing

The uploaded image is resized for efficient browser processing and converted into grayscale information.

2. Drawing Generation

A lightweight edge-based process extracts visual contours and converts them into a drawing-like representation.

3. Glitter Generation

Sparkle particles are generated near detected edges. Their size, opacity and density change with the selected intensity.

4. Layer Blending

The drawing layer and glitter layer are composited to create the final artwork, which can be downloaded as PNG.
